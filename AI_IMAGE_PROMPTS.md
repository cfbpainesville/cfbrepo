## STYLE GUIDE FOR ALL IMAGES

**Consistent Style Requirements:**
- Style: Clean, modern, minimalist flat design with subtle gradients
- Color Palette: Sky blue (#0ea5e9, #0284c4), white, soft tan (#d2b48c), warm brown (#8b4513)
- Background: Transparent PNG or white background
- Shape: Rounded corners, soft edges
- Dimensions: 512x512px (will be resized as needed)
- Format: PNG with transparency
- Lighting: Soft, even lighting from top-left
- Shadows: Subtle drop shadows for depth
- Consistency: All icons should look like they're from the same icon family

## NAMING CONVENTION

Format: `{category}-{descriptor}.png`

Examples:
- `calendar-event.png` (not `event-calendar.png`)
- `email-envelope.png` (not `envelope-email.png`)
- `community-people.png` (not `people-community.png`)

This ensures:
- Alphabetical organization by primary concept
- Clear purpose identification
- Consistency across icon library

## BATCH GENERATION TIPS FOR NANO-BANANA

1. **Generate all icons in the same session** to maintain style consistency
2. **Use the style guide** at the beginning: "All icons should be minimalist flat design with sky blue (#0ea5e9) primary color, warm tan (#d2b48c) accents, rounded corners, soft shadows, 512x512px, transparent PNG"
3. **Test first batch** (5-7 icons) to establish visual consistency before generating all
4. **Save prompts** for potential regeneration or variations
5. **Request variations** if needed: lighter/darker versions, outlined versions, etc.

---

## POST-GENERATION TASKS

After receiving images from Nano-Banana:

1. **Review consistency** across all icons
2. **Optimize file sizes** (use tools like TinyPNG)
3. **Organize into folders** as specified above
4. **Update code** to replace emoji with `<Image>` components
5. **Test responsive sizing** on mobile/tablet/desktop
6. **Verify accessibility** (ensure sufficient contrast)
7. **Add alt text** descriptions for screen readers
