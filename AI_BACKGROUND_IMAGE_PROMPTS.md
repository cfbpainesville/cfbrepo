## STYLE GUIDE FOR BACKGROUND IMAGES

**Consistent Style Requirements:**
- Style: Photorealistic with artistic touch, soft focus backgrounds, inspirational
- Color Palette: Sky blue (#0ea5e9, #0284c4), golden hour lighting, warm tan (#d2b48c), soft whites
- Mood: Peaceful, hopeful, spiritual, welcoming, uplifting
- Composition: Rule of thirds, negative space for text overlay
- Dimensions: 1920x1080px (16:9) for hero backgrounds, 1200x800px for cards
- Format: JPG for photos, PNG if transparency needed
- Lighting: Natural, soft, golden hour preferred
- Effects: Subtle vignette, slight blur for text readability
- Text overlay ready: Keep central/upper area lighter for dark text

## IMPLEMENTATION GUIDE

### Image Sizes by Usage:

| Usage Type | Recommended Size | Format | Quality |
|------------|-----------------|--------|---------|
| Full-width Hero | 1920x1080px | JPG | 85-90% |
| Hero (mobile-first) | 1200x800px | JPG | 85-90% |
| Card backgrounds | 1200x800px | JPG | 80-85% |
| Card images | 800x600px | JPG | 80-85% |
| Section backgrounds | 1920x1080px | JPG | 80-85% |
| Texture overlays | 1920x1080px | PNG/JPG | 75-80% |

### Text Overlay Considerations:

For images with text overlay, request:
- Upper third or center kept lighter/darker as needed
- Slightly reduced contrast in overlay areas
- Vignette effect to frame text
- Gradient overlay-ready composition

### Optimization:

1. Generate at highest quality first
2. Use tools like TinyJPG or Squoosh to optimize
3. Create WebP versions for modern browsers
4. Implement lazy loading for below-fold images
5. Use Next.js Image component for automatic optimization

## PROMPT MODIFIERS FOR VARIATION

Add these to any prompt for different effects:

**For lighter/brighter:**
- "high key lighting"
- "bright and airy"
- "soft white light"

**For darker/moodier:**
- "low key lighting"
- "dramatic chiaroscuro"
- "moody and contemplative"

**For more blur:**
- "extra shallow depth of field"
- "f/1.4 aperture"
- "maximum bokeh effect"

**For sharper:**
- "crisp focus throughout"
- "deep depth of field"
- "f/8 aperture"

**For vintage feel:**
- "slight film grain"
- "vintage color grading"
- "nostalgic warmth"
