## 🎨 COLOR OVERLAY GUIDE

### Sky Blue Overlay (Welcoming, Spiritual)
```css
.overlay {
  background: linear-gradient(to bottom,
    rgba(14, 165, 233, 0.7),
    rgba(2, 132, 196, 0.6)
  );
}
```
Use for: Homepage, Visit, Contact, Ministries

### Dark Overlay (Serious, Reflective)
```css
.overlay {
  background: linear-gradient(to bottom,
    rgba(0, 0, 0, 0.8),
    rgba(0, 0, 0, 0.5)
  );
}
```
Use for: Sermons, Prayer, Worship moments

### Warm Overlay (Welcoming, Friendly)
```css
.overlay {
  background: linear-gradient(to bottom,
    rgba(210, 180, 140, 0.6),
    rgba(139, 69, 19, 0.4)
  );
}
```
Use for: Thanksgiving, Fellowship, Community events

### Subtle Texture (Background enhancement)
```css
.texture {
  opacity: 0.05;
  mix-blend-mode: multiply;
}
```
Use for: Section backgrounds, subtle depth

## 📱 RESPONSIVE CONSIDERATIONS

### Mobile (< 768px):
- Use portrait crops for hero images
- Increase overlay opacity (harder to read on small screens)
- Consider mobile-specific images (tighter crops)

### Tablet (768px - 1024px):
- Standard images work well
- Ensure text remains readable

### Desktop (> 1024px):
- Full-width hero images shine
- Can use subtle background textures
- More complex compositions work
